# GJ5 ERP | GOOD JOB 5 ERP

Professional Smart Business Management Software.

## Mobile Build Instructions (Android APK)

Follow these steps to generate your production-ready Android APK.

### 1. Build and Sync
Run this command in your project root:
```bash
npm run mobile:build
```

### 2. Generate APK via Android Studio
Run this command:
```bash
npm run mobile:open
```

---

## Desktop Build Instructions (Windows EXE)

### 1. Build Standalone EXE (via Tauri)
```bash
npm run tauri:build
```
