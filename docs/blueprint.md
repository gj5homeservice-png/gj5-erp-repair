# **App Name**: GJ5 Nexus

## Core Features:

- Intelligent Service Command: Unified dashboard with KPI summary cards and smart filtering grid for managing device repairs, sequential job IDs, and location mapping.
- Smart Troubleshooting Assistant: Generative AI tool that analyzes 'Issue / Notes' and recommends diagnosis steps and common repair procedures based on device category.
- WhatsApp Gateway Integration: Customizable free message automation using template redirection to launch separate browser-based communication flows.
- Dynamic Cloud Ledger: Real-time synchronization for repair calls, employee records, and petty cash logs using a high-availability cloud database to prevent data collisions.
- Invoice Forge: Calculation engine with GST toggles and three unique printable templates (Modern, Retail, Thermal) for immediate job-to-bill conversion.
- Attendance Face-Sync: Biometric-style photo capture for staff clock-in/out, linking time stamps to visual verification in the employee registry.
- Liquidity Pulse: E-wallet tracker for 'Parachu Ran' petty cash with visual breakdown charts for chai nasta and operational consumables.

## Style Guidelines:

- Background: Ultra-dark midnight blue (#0B0F19); Primary color: Electric Blue (#0066FF) for core interface elements and buttons.
- Semantic Accents: Cyber Yellow (#FFD700) for warnings/pending states and Vivid Crimson (#FF3366) for errors/rejected calls.
- Headlines use 'Space Grotesk' for a high-tech feel; Body text uses 'Inter' for machined clarity; Technical IDs utilize 'Source Code Pro'.
- Vector-based mono-weight icons for system tabs and inline map pins to ensure crisp rendering on high-density displays.
- Side-panel navigation focused with a responsive split-view for table data and interactive modals.
- Smooth status transitions in the KPI cards and progressive loading states for webcam-based face capture components.
